# Security Policy

## Supported versions

The latest released version on the `main` branch receives security updates.

## Reporting a vulnerability

Please **do not** open public issues for security vulnerabilities.

Instead, email **[support@viprasol.com](mailto:support@viprasol.com)** with:

- a description of the issue and its impact,
- steps to reproduce, and
- any suggested remediation.

We aim to acknowledge reports within 3 business days and to provide a remediation
timeline after triage. Responsible disclosure is greatly appreciated.
